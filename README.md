# winomedia – Light & Elegant / Premium

Astro-Website für das GitHub-Repository `WinoMedia/winomedia`.

## Aktualisieren

Lade den **Inhalt** dieses Ordners in die oberste Ebene deines GitHub-Repositories. Bestehende Dateien gleichen Namens ersetzen; den Ordner `.github/workflows` beibehalten. Die Veröffentlichung erfolgt via GitHub Actions.

## Logo-Hinweis

`public/assets/data-flow-original-logo.png` ist ein unveränderter Bildausschnitt aus der bestätigten Markenpräsentation, **keine transparente SVG-Vektordatei**. Das originale Logo wird im grossen Hero-Markenpanel und im Über-uns-Bereich verwendet. Das kleine Header-Monogramm ist typografisch und nur eine Übergangslösung, keine exakte WM-Nachzeichnung.

## Vor Veröffentlichung ergänzen

E-Mail-Platzhalter in `src/pages/index.astro` ersetzen, Impressum/Datenschutz ergänzen, persönliche Vorstellung prüfen.
